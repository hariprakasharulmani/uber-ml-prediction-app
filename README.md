# Uber Rides Prediction App

A Machine Learning web application that predicts the number of weekly Uber rides based on economic and demographic factors.

## 🚀 Live Demo
https://uber-ml-prediction-app.onrender.com/

## 🛠 Tech Stack
- Python
- Flask
- Scikit-learn
- NumPy
- Gunicorn
- Render (Deployment)

## 📊 Features
- ML model trained using regression
- Web interface built with Flask
- Production deployment using Gunicorn
- Hosted on Render

## 📦 Installation (Local Setup)

1. Clone repository
2. Create virtual environment
3. Install dependencies:
   pip install -r requirements.txt
4. Run:
   python app.py
